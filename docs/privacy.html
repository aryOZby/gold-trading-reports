Privacy policy

Gold Reports is a private tool used only by its owner. It has no other users.

Google data it uses

  • Google Drive (drive.file): creates a "Gold Trading Reports" folder in the owner's Drive and uploads or replaces the monthly report files in it. It can only see files and folders it created itself.
  • Gmail (gmail.send): sends the monthly report email from the owner's account. It does not read, list, or delete any email.

Storage and sharing

The sign-in token is stored only on the owner's server and is used only to perform the two actions above. No Google user data is sold, shared with third parties, or used for advertising or any purpose other than delivering the owner's own reports.

Revoking access

Access can be removed at any time at myaccount.google.com/connections.
